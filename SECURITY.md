# Security policy

## Supported versions

evalkit is on 0.x. Security fixes go into the latest release only; upgrade
to get them. Releases are listed on the
[releases page](https://github.com/inferedge-ai/evalkit/releases).

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues, Discussions
or pull requests.

- **Preferred:** report it privately through
  [GitHub](https://github.com/inferedge-ai/evalkit/security/advisories/new)
  ("Report a vulnerability" on the Security tab).
- **Or email** [tech+security@inferedge.com](mailto:tech+security@inferedge.com).

Include what you can: the affected version, steps to reproduce, and the
impact you expect. We'll confirm we received your report, keep you updated
while we work on a fix, and credit you in the advisory if you'd like.
